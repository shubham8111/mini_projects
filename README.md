# mini_projects
POCs by Claude Code

## Projects

### [Decibel Meter](decibel_meter/)
A web-based decibel meter that uses your device's microphone to display real-time audio levels with a visual bar meter, numeric readout, and calibration support.

### [Tic Tac Toe — Vanishing Marks Edition](tic_tac_toe/)
A twist on classic Tic Tac Toe where each player can hold at most 3 marks on the board at any time. When a player places their 4th mark, their oldest mark disappears — keeping the board dynamic and forcing constant re-evaluation of position.
